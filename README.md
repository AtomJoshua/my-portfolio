# Atom Enoch Joshua — Portfolio

Personal portfolio and technical showcase engineered with React 19, Vite, Tailwind CSS v4, and Framer Motion.

Live at: [atom.name.ng](https://atom.name.ng)

## Architecture & Tech Stack

- **Framework:** React 19 (SPA routing via `react-router-dom` v7)
- **Styling:** Tailwind CSS v4 + `@tailwindcss/vite`
- **Animations:** Framer Motion
- **Icons:** Lucide React
- **Messaging:** EmailJS Client Integration
- **Deployment:** Vercel

## Local Development

```bash
git clone [https://github.com/AtomJoshua/atom-portfolio.git](https://github.com/AtomJoshua/atom-portfolio.git)
cd atom-portfolio
npm install
npm run dev
```
